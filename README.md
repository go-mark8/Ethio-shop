# Ethioshop 🛒

Ethioshop is a Flutter-based e-commerce mobile application powered by Firebase.

## 🚀 Features
- Firebase Authentication
- Firestore database
- Secure user accounts
- Product listing & orders
- Android Play Store ready

## 🧱 Tech Stack
- Kotlin 
- Firebase Auth
- Cloud Firestore
- Gradle (Android)
- GitHub + IDX workflow

## 📦 Project Setup

### Prerequisites
- Kotlin SDK (latest stable)
- Android Studio or IDX
- Firebase project
